# Каталог настільних ігор (Board Games Catalog)

Повноцінний Full-Stack вебзастосунок для перегляду та керування власною колекцією настільних ігор. Проєкт створено в рамках фінальної практичної роботи з веб-розробки. Застосунок поєднує сучасний клієнтський інтерфейс на React із локальним REST API сервером на Node.js.

## Основний функціонал

- **Клієнтський роутинг (Hash-based):** Швидка навігація між сторінками без перезавантаження браузера (Головна `#/`, Колекція `#/owned`, Деталі гри `#/games/:id`).
- **Локальний API-сервер:** Отримання каталогу ігор та їх деталей через власні ендпоінти (`/api/games` та `/api/games/:id`).
- **Динамічна фільтрація:** Зручний пошук ігор за назвою, кількістю гравців та жанром.
- **Робота з локальними базами даних:** Збереження статусу ігор ("Зіграно" / "Не грали") в браузерній базі **IndexedDB** із підтримкою міграції старих даних із `localStorage`.
- **CSS-анімації:** Плавна поява карток (`fadeInScale`) та динамічне виділення "Гри дня" ефектом пульсації (`pulseBorder`).
- **Адаптивний дизайн:** Коректне відображення сітки ігор на мобільних телефонах, планшетах та десктопах.

## Технологічний стек

**Фронтенд:**
- React (впроваджено через CDN)
- JavaScript (ES6+), HTML5, CSS3
- IndexedDB (збереження стану користувача)

**Бекенд:**
- Node.js
- Express (роздача статики та REST API)

Звіт з аудиту безпеки (Security Report)
В рамках розробки застосунку було проведено комплексний аудит безпеки за ключовими критеріями:

1. Захист від XSS-атак (Міжсайтовий скриптинг)
Підтвердження вразливості: Під час тестування поле title було навмисно скомпрометовано рядком <img src=x onerror="alert('XSS')"> через використання небезпечного методу dangerouslySetInnerHTML. Вразливість підтвердилася виконанням шкідливого скрипта.

Виправлення: Вивід усіх динамічних даних з API переписано через стандартні JSX-вирази {title}. React автоматично екранує ці значення під капотом (використовуючи textContent), що гарантовано перетворює будь-який HTML-код на безпечний текст і повністю блокує XSS-атаки.

2. Безпека локального сховища
Було проаналізовано вкладку Application -> IndexedDB (база BoardGamesDB).

Висновок: Сховище містить виключно публічні дані каталогу (назви ігор, кількість гравців, час, жанри та статус наявності). Чутливої інформації, такої як паролі, персональні дані користувачів чи токени авторизації, у локальних сховищах браузера не виявлено. Використання IndexedDB у цьому проєкті є безпечним.

3. Відсутність захардкоджених секретів
Проведено аналіз клієнтського (app.js) та серверного (api/index.js) коду. У застосунку відсутні захардкоджені API-ключі, паролі до зовнішніх баз даних чи секретні токени. Дані обробляються локально без потреби у зовнішній автентифікації.

4. Використання HTTPS при розгортанні
Для фінального розгортання проєкту в продакшен-середовищі (production) обрано платформу Vercel. Ця платформа автоматично генерує SSL-сертифікат і маршрутизує трафік виключно через захищений протокол HTTPS за замовчуванням. Це забезпечує надійне шифрування каналу зв'язку та унеможливлює перехоплення даних зловмисниками (MitM-атаки).
